# MultiSession Browser

A private Android browser with session isolation, desktop mode, and URL bar suggestions.

## Features

- **Session isolation** — Each browsing session is fully separated
- **Desktop mode** — Desktop user-agent with viewport scaling and MutationObserver
- **URL bar suggestions** — Search, history, and bookmark suggestions as you type
- **Multi-tab** — Multiple tabs per session with tab management
- **Download manager** — Built-in download handling
- **Dark/light themes** — System, light, and dark theme support

## Install

1. Download the APK from the releases page above
2. Enable "Install from unknown sources" on your device
3. Open the APK and install

## Permissions

- `INTERNET` — Browse the web
- `WRITE_EXTERNAL_STORAGE` — Save downloads (Android < 10)
- `FOREGROUND_SERVICE` — Keep downloads alive in background
